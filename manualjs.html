Antes de começar: onde o JavaScript fica?

JavaScript interno no HTML

O navegador lê o HTML, encontra os elementos da página e executa o JavaScript colocado dentro de uma tag <script>. Neste manual, os laboratórios usam principalmente JavaScript interno: HTML e JavaScript ficam no mesmo arquivo.

1. O HTML cria o elemento

Primeiro colocamos o botão, texto, imagem, campo etc. dentro do <body>.

<button id="meuBotao">Clique aqui</button>
<p id="mensagem">Aguardando...</p>

2. O JavaScript encontra o elemento

Depois, normalmente colocamos o <script> no final do <body>. Assim o HTML já foi criado quando o JavaScript procurar os elementos.

<script>
  const botao = document.querySelector('#meuBotao');

  botao.addEventListener('click', () => {
    document.querySelector('#mensagem').textContent = 'Funcionou!';
  });
</script>
</body>
📍 Regra visual deste manual: <body> contém o que aparece na tela; <script> contém o comportamento. Nos exemplos abaixo, procure sempre primeiro o elemento HTML e depois o código JavaScript que dá vida a ele.

Uso 1 — direto no HTML

<button onclick="alert('Olá!')">Clique</button>

É possível escrever JavaScript diretamente em um atributo como onclick. É útil para demonstrar rapidamente um conceito, mas em projetos maiores preferimos separar HTML e JavaScript.

Uso 2 — script interno

<body>
  <button id="btn">Clique</button>

  <script>
    document.querySelector('#btn').onclick = () => {
      alert('Olá!');
    };
  </script>
</body>

É o padrão usado nos laboratórios deste manual.

Uso 3 — JavaScript externo

<script src="script.js" defer></script>

Quando o projeto cresce, o JavaScript pode ficar em um arquivo separado. O atributo defer permite carregar o script sem bloquear a construção da página.
